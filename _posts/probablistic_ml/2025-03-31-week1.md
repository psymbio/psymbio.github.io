## Variance of the Bernoulli Distribution

A **Bernoulli distribution** describes a random variable $X$ that takes values:

$$X = \begin{cases} 1, & \text{with probability } p \\ 0, & \text{with probability } 1 - p\end{cases}$$

### 1. Expected Value $E[X]$
The expected value (mean) is defined as:

$$E[X] = \sum_{x} x \cdot P(X = x)$$

For a Bernoulli random variable:

$$E[X] = (1 \cdot p) + (0 \cdot (1 - p)) = p$$

### 2. Expected Value of $X^2$

The expected value of $X^2$ is calculated using the definition:

$$E[X^2] = \sum_{x} x^2 \cdot P(X = x)$$

For a Bernoulli random variable, $X$ takes values $0$ and $1$ with probabilities $1 - p$ and $p$, respectively. We compute $E[X^2]$ step by step.

#### **Step 1: Compute $X^2$ for each value of $X$**
- If $X = 1$, then $X^2 = 1^2 = 1$
- If $X = 0$, then $X^2 = 0^2 = 0$

Thus, in general, for any Bernoulli variable, we observe:

$$X^2 = X$$

#### **Step 2: Apply the Expectation Formula**
Using the expectation formula:

$$E[X^2] = (1^2 \cdot P(X = 1)) + (0^2 \cdot P(X = 0))$$

Substituting the given probabilities:

$$E[X^2] = (1 \cdot p) + (0 \cdot (1 - p))$$

#### **Step 3: Simplify the Expression**
Since $0 \cdot (1 - p) = 0$, we get:

$$E[X^2] = p$$

Thus, we conclude:

$$E[X^2] = p$$

This result makes sense because, for a Bernoulli variable, squaring does not change the value, meaning $E[X^2]$ is the same as $E[X]$.

### 3. Variance Formula
Variance is defined as:

$$\text{Var}(X) = E[X^2] - (E[X])^2$$

Substituting the values:

$$\text{Var}(X) = p - p^2$$

$$\text{Var}(X) = p(1 - p)$$

### 4. Interpretation
- The variance is highest when $p = 0.5$, meaning maximum uncertainty.
- The variance is $0$ when $p = 0$ or $p = 1$, meaning no uncertainty (constant outcomes).
- The formula $p(1 - p)$ represents the spread of probability between success $(1)$ and failure $(0)$.

Thus, the **variance of a Bernoulli distribution** is:

$$\text{Var}(X) = p(1 - p)$$
